> 《深度学习技术与应用》课程公开教学资源 · 第一章
> 面向计算机专业本科生的深度学习入门课，理论 32 学时 + 实践 16 学时

## 课程简介

《深度学习技术与应用》是面向具有 Python 与高等数学基础学生的深度学习入门课程。课程从深度学习的发展脉络与数学基础切入，逐步深入神经网络、卷积神经网络、循环神经网络等核心模型，结合 PyTorch 框架通过基础实操、技术实战及项目落地的递进式实践环节，帮助学生完成从理论理解到代码实现，再到问题解决的全链路过程。

**第一章《深度学习概述》**（3 学时）是整门课的地基，回答三个问题：

1. **深度学习是什么**——人工智能、机器学习、深度学习的关系，深度学习的定义与"三要素"框架（模型、损失、优化）
2. **它怎么来的**——从 1958 年感知机到 2017 年 Transformer 的六十年历程，三次浪潮与两次寒冬，特征学习革命与端到端学习
3. **怎么用起来**——搭建 PyTorch 开发环境，跑通第一个深度学习程序

## 交互实验台使用说明

**打开方式**：双击 `交互实验台/index.html` 进入总入口，或直接双击单个实验台 HTML 文件，在浏览器中打开即可（无需联网、无需安装任何依赖）。

| 实验台 | 对应知识点 | 课堂玩法 |
|--------|-----------|----------|
| ① 感知机训练台 | 感知机学习规则、线性可分、学习率 | 自动训练看直线切开两类点；切换到"异或"数据观察不收敛（第一次寒冬的死穴） |
| ② 梯度下降小球 | 梯度下降、学习率 | 拖学习率：η 小走不动、η 合适直抵谷底、η 大来回震荡甚至发散 |
| ④ 过拟合发生器 | 过拟合/欠拟合、泛化 | 拖多项式阶数：1 是欠拟合、15 是过拟合，找到泛化最好的"甜区" |
| ⑤ 网页版 HelloDL | 训练循环、前向/损失/反向/更新 | 对应课件 p.84–85 的 10 行代码，看决策线移动与 loss 曲线下降 |

## 上机实践使用说明

**环境要求**：Anaconda + Python 3.10 + PyTorch（CPU 版即可，有 NVIDIA 显卡可装 CUDA 版）

```bash
# 1. 创建并激活课程环境（环境名 dl2026）
conda create -n dl2026 python=3.10
conda activate dl2026

# 2. 安装 PyTorch（CPU 版，无显卡用这个）
pip install torch torchvision

# 3. 运行第一个程序
python 01_环境验证.py
python 03_hello_deep_learning.py
```

详细的安装步骤（Anaconda 下载、清华镜像配置、PyTorch 安装向导）见 `上机实践/README.md`。
