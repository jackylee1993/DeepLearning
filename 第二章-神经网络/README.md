> 《深度学习技术与应用》课程公开教学资源 · 第二章
> 面向计算机专业本科生的深度学习入门课，理论 32 学时 + 实践 16 学时

## 课程简介

《深度学习技术与应用》是面向具有 Python 与高等数学基础学生的深度学习入门课程。课程从深度学习的发展脉络与数学基础切入，逐步深入神经网络、卷积神经网络、循环神经网络等核心模型，结合 PyTorch 框架通过基础实操、技术实战及项目落地的递进式实践环节，帮助学生完成从理论理解到代码实现，再到问题解决的全链路过程。

**第二章《神经网络》**（3 学时）承接第一章的"三要素"框架，回答一个核心问题：**网络到底是怎么"学会"的？**

1. **课时一 · 前馈神经网络（FFN）**——从生物神经元出发，把"收、算、发"翻译成"加权求和 + 激活"；看清 FFN 的骨架（输入层 / 隐藏层 / 输出层）；理解隐藏层为什么重要（特征加工车间、万能逼近），并用逻辑门与 XOR 验证单层的能力边界
2. **课时二 · 反向传播（BP）**——把"学习"翻译成"求导"；用链式法则一层层倒传误差；手推数值走查；看清梯度消失的由来与解药；收束为"五步舞曲"训练循环
3. **课时三 · 上机实践**——用 PyTorch 亲手搭建 64→32→10 的两层网络，在真实手写数字数据上完成"数据 → 网络 → 训练 → 评估 → 可视化"全流程

## 交互实验台使用说明

**打开方式**：双击 `交互实验台/index.html` 进入总入口，或直接双击单个实验台 HTML 文件，在浏览器中打开即可（无需联网、无需安装任何依赖）。

| 实验台 | 对应知识点 | 课堂玩法 |
|--------|-----------|----------|
| ① 神经元逻辑门 | 感知机、权重与偏置、决策线 | 点 AND/OR/NAND 预设看决策线切分数据；手动拖权重体会"调参数 = 改行为"；挑战调出 XOR——调不出来，这正是单层感知机的天花板 |
| ② 反向传播模拟台 | 前向传播、链式法则、参数更新 | 单步或自动训练，看计算图里数值如何前向算出损失、误差如何倒传、w/b 如何更新；把学习率调到 0.5+ 看 loss 震荡 |
| ③ 隐藏层与 XOR | 隐藏层、空间变换、特征重表达 | 左图切不开的 XOR，经隐藏层变换后在右侧新空间被一条竖线分开——亲眼看见"换坐标系"的威力 |

## 上机实践使用说明

**环境要求**：Anaconda + Python 3.10 + PyTorch（CPU 版即可）+ scikit-learn + tensorboard

```bash
# 1. 创建并激活课程环境（环境名 dl2026）
conda create -n dl2026 python=3.10
conda activate dl2026

# 2. 安装依赖（CPU 版）
pip install torch scikit-learn tensorboard

# 3. 按顺序运行
cd 上机实践
python 01_数据准备.py
python 03_训练循环.py
python 04_评估.py
```

训练配置：Adam（lr=1e-2）、100 个 epoch、隐藏层 32 个神经元，测试集准确率约 **91%~92%**。

详细的运行说明与"报错锦囊"见 `上机实践/README.md`。
