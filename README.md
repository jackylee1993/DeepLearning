# 深度学习· Deep Learning
> 🎓 高校课程 · 从零到一学深度学习 · 理论 + 交互实验 + 代码实践三合一
> 适合：计算机专业高年级本科生、AI 初学者、想系统入门深度学习的自学者

---

## 🚀 这门课有什么不一样？

大部分深度学习课程要么"只讲理论"（听完还是不会写代码），要么"只讲代码"（调包侠式学习，不懂原理）。这门课把两者打通：

| 维度 | 课程设计 | 你会得到 |
|------|----------|----------|
| 📖 理论 | 从 1958 感知机讲到 2022 大模型，**讲清"为什么"而不只是"是什么"** | 完整的知识地图，而不是碎片概念 |
| 🧪 交互实验 | 每个抽象概念配一个**可动手的交互实验台**（浏览器即开即用） | 亲手"看见"梯度下降、过拟合、感知机学习 |
| 💻 代码实践 | 全程 **PyTorch**，从环境搭建到完整训练循环逐行拆解 | 学完能独立跑通深度学习项目 |
| 🎯 学习路径 | "模型-损失-优化"三要素框架贯穿全课程 | 任何新模型都能用同一框架快速理解 |

**课程主线**：不是按模型罗列知识，而是沿着一条问题链展开——机器怎么"学会"看和听？为什么深度学习"死"了两次又活了两次？端到端学习凭什么取代特征工程？带着问题学，知识才是活的。

## 🚀 快速开始

### 方式一：只看课件（零门槛）

直接下载 [`第一章-深度学习概述/深度学习—第一章.pdf`](第一章-深度学习概述/深度学习—第一章.pdf)，跟着讲稿自学即可。

### 方式二：动手玩交互实验（推荐）

```bash
# 克隆仓库
git clone https://github.com/你的用户名/深度学习技术与应用.git
cd 深度学习技术与应用/第一章-深度学习概述/交互实验台
# 双击 index.html，或直接用浏览器打开
```

> 💡 所有实验台都是**纯 HTML 单文件**，无需联网、无需安装任何依赖，发给学生/朋友双击就能玩。

### 方式三：完整代码实践

```bash
# 1. 安装 Anaconda 后创建环境
conda create -n dl2026 python=3.10
conda activate dl2026

# 2. 安装 PyTorch（CPU 版即可开始）
pip install torch torchvision

# 3. 进入上机实践目录，从环境验证开始
cd 第一章-深度学习概述/上机实践
python 01_环境验证.py
python 03_hello_deep_learning.py
```

## 📖 学习建议

1. **先看课件**，带着"它要解决什么问题"的疑问看，而不是记概念
2. **再玩实验台**，抽象概念玩 2 分钟比读 20 分钟记得牢
3. **最后写代码**，看懂 ≠ 会写，把示例代码亲手敲一遍
4. 遇到报错先自己读错误信息，再查 `上机实践/README.md` 的报错锦囊
